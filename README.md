# HighMoon2

## Spielidee
HighMoon2 ist ein kleines TypeScript-Browserspiel: Zwei Schiffe kämpfen in einem Asteroidenfeld mit Gravitations-Physik gegeneinander.

![Screenshot von HighMoon2 (1024 x 768)](https://github.com/user-attachments/assets/33fb958a-29d1-42fd-b014-25a89f462ac8)

## Stack
- TypeScript 6
- Browser Canvas 2D
- Web Audio API

## Installation
```bash
npm install
npm run build
```

## Anleitung
- Danach `index.html` im Browser öffnen.
- `Enter`: Spiel starten / neu starten
- `ArrowLeft` / `ArrowRight`: Schiff drehen
- `ArrowUp` / `ArrowDown`: Schiff vertikal bewegen
- `Space`: Schießen
